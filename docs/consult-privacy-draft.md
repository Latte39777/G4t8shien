## A. サービスの説明

### このアプリが提供する機能と目的

- 子育て・教育・住宅・就労などに関する支援制度について、**シミュレーション（試算）**と**相談（質問応答）**ができる Web アプリです。
- シミュレーションでは、お子さまの人数・年齢や家計の状況などの入力に基づき、公的支援と費用の見込みを試算して表示します。
- 相談機能では、支援制度について自由に質問し、回答を受け取ることができます。現在の開発段階では回答は開発用のサンプル（モック）です。将来、AI による回答機能を有効にする場合は、この文書の「C. 保存と送信」に記載する取り扱いをあらかじめお知らせします。

### 制度案内やシミュレーションは参考情報であり、行政機関の正式な判定ではないこと

- このアプリに表示される制度情報・試算結果・相談の回答は、**参考情報**です。行政機関や学校などによる正式な判定・決定・審査結果ではありません。
- 試算結果には仮定値・未確認のデータが含まれる場合があり、金額・対象条件は実際のものと異なる可能性があります。
- 制度情報には、公式の資料と照合済みの情報と、まだ確認が取れていない情報が混在しています。どの情報が確認済みかは、各項目の表示（確認状況のバッジや要確認項目）をご確認ください。

### 最終的な受給資格・金額・申請期限は公式窓口で確認する必要があること

- 受給資格（対象になるかどうか）、支給される金額、申請の期限や方法は、お住まいの自治体や各制度の公式窓口で必ずご確認ください。
- このアプリの表示は、公式窓口での確認に代わるものではありません。

## B. 入力を避けるべき情報

### 相談に不要な個人情報は入力しないでください

- 相談や質問の入力欄には、次の情報は**入力しないでください**。相談内容を整理するためにこれらは必要ありません。
  - 氏名・生年月日などの本人を特定する情報
  - 住所・電話番号・メールアドレスなどの連絡先
  - マイナンバー（個人番号）などの公的な番号
  - 銀行口座・クレジットカードなどの金融情報
  - その他、健康状態や家族関係など、相談に不要と思われる詳細な個人情報
- 代わりに、「子どもが2人いる」「年収の入力をした」「〜の制度を利用している」のように、**状況を整理するための一般的な範囲**でお書きください。

### マスキング機能の限界（重要）

- 相談内容を外部の AI サービスへ送信する前に、個人情報らしき文字列を置き換える**マスキング（伏せ字化）の処理**を実装しています。現在の実装で置き換えの対象となるのは、**メールアドレス**、**電話番号**（例: 090-1234-5678、090 1234 5678、０９０‐１２３４‐５６７８のように、半角/空白/全角数字や区切り記号（全角・異体字を含む）を用いた形式）、**12桁の番号（4-4-4 形式）**、**8桁以上つづる数字**、**郵便番号**（〒123-4567 や 123-4567 のような 3-4 の区切り形式）などに限られます。
- ただし、このマスキングは**完全なものではありません**。すべての個人情報を検出・削除できるとは**保証しません**。例えば、**氏名・住所・カタカナ表記の氏名**、**桁数の少ない数字（口座番号など。郵便番号の形式を除く）**は、置き換えの対象になりません。また、金額などの数字の範囲表記（例: 100-2000）は郵便番号の形式と区別できず、**必要以上に置き換わることがあります**。機械的に確実に見分けることはできません。
- マスキングは、個人情報保護のための**完全な保証としての機能ではありません**。個人情報を含めないようご利用いただくことが重要です。

## C. 保存と送信

現在は開発段階（モック環境）で運用しています。**現在のモック環境**と、**将来 AI 回答機能（ライブAI）を有効にする場合**で、データの取り扱いが異なります。

### C-1. 現在のモック環境（実装で確認できた範囲）

- **会話履歴（質問と回答）は、お使いのブラウザのメモリ上にのみ一時的に保持されます。** localStorage・sessionStorage・サーバー側のデータベースなどには保存しません。ページをリロードしたりブラウザを閉じたりすると消えます。
- 質問の内容は、開発用のサンプル回答（モック）を生成するために処理されますが、**外部の AI サービスや外部サイトへは送信されません**（外部への通信は行っていません）。
- 相談機能では、シミュレーションの入力情報のうち「お子さまの人数・世帯年収の入力の有無・利用中の制度の件数」などの最小限の情報のみを利用しています。**収入・貯蓄などの金額（入力フォームの数値）は相談機能には渡していません。**ただし、質問文に自ら書き込んだ金額は、相談の本文として扱われます（C-2 の送信対象に含まれ得ます）。
- シミュレーションの入力内容（家計の状況など）も、サーバーへ送信・保存されず、試算の処理と表示のためにブラウザ内で一時的に利用されるのみです（ページを離れると消えます）。
- サーバー側では、相談本文を含む記録を保存する設計にはなっていません（処理の障害調査用のエラー情報のみを出力します。詳細は付録の「ログ」の項を参照）。

### C-2. 将来ライブAIを有効にする場合（公開前の対応事項を含む）

- 将来、AI 回答機能（ライブAI）を有効にする場合、**質問文や関連する相談情報が外部の AI サービスへ送信されます**。このことは、**送信前に利用者へお知らせする設計とします**（現在は未実装のため、公開前の対応事項です）。
- 外部 AI サービスに送信される可能性がある情報の種類（現行の実装設計に基づく）:
  1. **質問文**（マスキング処理・文字数制限の後。質問文に自ら書き込んだ金額や個人情報は、マスクの対象にならない場合があります）
  2. **会話履歴**（直近の質問と回答・マスキング処理の後。履歴の本文に含まれる金額・個人情報も同様です）
  3. **相談のきっかけとなった制度の名前と概要**（制度カードから相談を開始した場合。制度の ID・金額の説明・窓口・申請期限などの項目は含みません）
  4. **相談者の状況のごく一部**（お子さまの人数・世帯年収の入力の有無・利用中の制度の**件数**。金額・氏名・住所・制度の ID・利用実績の詳細は含みません）
  5. **公式情報の確認済みの事実**（制度の公表値・確認記録。支給額などの公表値を含み得ます。URL・利用者情報は含みません）
- 構造化された入力の金額（**収入・貯蓄などの金額**・年収額）は送信しません。氏名・連絡先・マイナンバー等の本人情報や利用中制度の ID を、構造化データとして送信することもありません。ただし、**質問文・履歴に自ら書き込んだ情報**は本文の一部として送信され、マスクは完全ではないため（B のとおり）、個人情報の入力は避けてください。
- 送信の前に利用者へ告知し、必要な同意を取得する方法は「E. 公開前の未確定事項」のとおり**未実装・未確定**です。実装済みであるかのような説明はしません。
- ライブAI の有効化は、大学の利用条件の確認・承認が得られるまで行いません。

### C-3. 外部AI提供者のデータ取り扱い（公開前に確認・記載する項目）

- 外部 AI 提供者（大学提供の API）による入力データ・ログの**保存期間**、**学習利用の有無**、**ログ保持の方針**、**第三者提供の有無**は、**公式な条件を確認できていない限り断定しません**。
- 現時点で確認できているのは、一般的な AI プラットフォームの紹介資料に「ベンダー側の学習に利用履歴は使われない」「組織の管理ポリシーに基づき、会話ログを応答品質向上に組織内で利用できる」との記載があることのみです。ただし、この記載が実際に利用する API に適用されるかは**未確認**です（対応関係が確認できていないため）。
- 上記はすべて**公開前に確認・記載する項目**です。確認が取れた内容に基づき、この文書に保存期間・学習利用の有無・ログの扱い・第三者提供の条件を追記します。

## D. 回答の限界と安全な利用

### AI・シミュレーションの回答には限界があります

- 相談機能の回答（AI による回答を含む）には、**誤りや古い情報を含む可能性**があります。制度の改正や情報の更新に間に合っていない場合があります。
- 回答は、確認が取れている情報の範囲で作成していますが、正確さ・完全さを保証するものではありません。

### 受給資格・受給可否・法的権利を自動判定するものではありません

- このアプリは、**受給資格（対象かどうか）や受給可否を自動的に判定するものではありません**。法的な権利の有無を決定するものでもありません。
- 回答に「〜の可能性があります」などの表現が含まれていても、正式な判定ではありません。

### 給付・授業料減免・貸与型制度の違いに注意してください

- 支援制度には、返還の不要な**給付**、費用が軽減される**減免**、返済が必要な**貸与（借り入れ）**、税の仕組みによる**減税**など、種類が異なるものが含まれます。
- 特に**貸与型（奨学金など）**は、返済の義務が生じます。このアプリでは制度の種類を区別して表示していますが、契約条件は必ず各制度の窓口でご確認ください。

### 重要な判断は各制度の公式情報・窓口に確認してください

- 申請するかどうかの判断、金額の見込み、期限の確認など、**重要なことは各制度の公式情報・公式窓口で確認**してください。
- このアプリの内容のみを根拠に、申請を急ぐ・辞めるなどの判断をされないようお願いします。

### 緊急性の高い相談・専門的な判断が必要なケースへの対応

- このアプリは、緊急性の高い相談（生活の危機、医療・法律・DV などの専門的な対応が必要なケース）に**確実に対応できるとは約束できません**。
- そのような場合は、自治体の窓口、公的な相談機関、専門家（弁護士・社会保険労務士・医師など）にご相談ください。
